# 📂 데이터 디렉토리 (data/)

프로젝트에 사용되는 모든 데이터가 관리되는 곳입니다.

## 📁 구조

- **raw/**: 외부에서 수집된 원본 데이터. 이 폴더의 파일은 절대 직접 수정하지 않습니다.
    - `google_trends/`: 구글 트렌드 검색량 CSV 파일
    - `stock/`: 종목별 주가 데이터 CSV 파일
- **processed/**: `src/processing/processor.py`에 의해 생성된 데이터.
    - 결측치 처리, 이상치 정규화, 피처 엔지니어링이 완료된 데이터 세트가 저장됩니다.

## ⚠️ 주의사항
- `processed/` 폴더의 데이터는 파이프라인 실행 시마다 갱신될 수 있으므로, 영구 보관이 필요한 데이터는 별도로 관리하십시오.
- 원본 데이터의 형식이 변경될 경우 `src/processing/processor.py`의 로직도 함께 업데이트해야 합니다.
