# 📊 분석 리포트 (reports/)

모델 평가 결과, 성능 지표, 그리고 각종 시각화 자료가 저장되는 곳입니다.

## 📈 주요 산출물
- **Figures (.png)**:
    - `feature_importance.png`: 모델이 중요하게 판단한 변수들
    - `confusion_matrix_comparison.png`: 예측 결과의 혼동 행렬
    - `pr_curve_comparison.png`: Precision-Recall 곡선
    - `target_correlation.png`: 타겟 변수와 피처 간의 상관관계
- **Metrics (.csv)**:
    - `model_classification_metrics.csv`: 전체 모델의 Accuracy, F1-score 등 수치 데이터
    - `ticker_performance_summary.csv`: 종목별 예측 성능 요약

## 💡 분석 활용
이 폴더의 결과물은 프로젝트 보고서(`PROJECT_REPORT.md`) 작성의 기초 자료로 활용됩니다.
