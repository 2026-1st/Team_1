# Model 1 Experiment Report: Logistic Regression

## 4. Experiment

이 절에서는 모델 1인 Logistic Regression의 실험 설계, 데이터셋 구성, 실험 환경, 평가 지표를 정리한다. 본 실험은 동일한 전처리 데이터와 동일한 시계열 분할 조건에서 주가 방향 예측 성능을 확인하는 것을 목표로 하였다.

### 4.1 Dataset

| 항목 | 내용 |
|---|---|
| 데이터셋 | 국내 주요 기업 주가 데이터 + Google Trends 검색량 데이터 |
| 데이터 파일 | `data/processed/all_companies_model_data.csv` |
| 예측 목표 | 다음 거래일 주가 방향 예측 |
| Target | `target`, 0: 하락 또는 상승 아님, 1: 상승 |
| 전체 표본 수 | 1,307개 |
| Train / Val / Test | Train 914개, Validation 196개, Test 197개 |
| 기업 수 | 6개 기업 |
| 주요 피처 | 주가, 거래량, 수익률, 이동평균, 변동성, 국내/글로벌 검색 트렌드 |
| 출처 | 프로젝트 내 수집 데이터, 주가 데이터 및 Google Trends 기반 검색량 데이터 |

입력 피처는 크게 주가 기반 피처와 검색 트렌드 기반 피처로 구성하였다. 주가 기반 피처에는 `Open`, `High`, `Low`, `Close`, `Volume`, `return_lag1`, `return_lag3_mean`, `ma5_gap`, `ma20_gap`, `volatility_7` 등이 포함된다. 검색 트렌드 기반 피처에는 `trend_kor`, `trend_glb`, `weighted_trend`, `trend_lag1`, `trend_lag3_mean`, `trend_lag7_mean`, `trend_change` 등이 포함된다.

![EDA distribution](figures/model1/01_eda_distribution.png)

Target 분포를 확인한 결과 전체 데이터에서 상승 클래스가 하락 클래스보다 약간 많았지만, 극단적인 클래스 불균형은 아니었다. 기업별로는 일부 기업에서 상승/하락 비율 차이가 존재하였다. 따라서 모델 학습 시 `class_weight="balanced"`를 적용하여 클래스 비율 차이에 따른 편향을 완화하였다.

![Feature correlation heatmap](figures/model1/02_feature_correlation.png)

상관관계 분석 결과, `target`과 개별 feature 간의 선형 상관관계는 전반적으로 낮았다. 예를 들어 `weighted_trend`와 `target`의 상관계수는 약 -0.07, `return_lag1`과 `target`의 상관계수는 약 -0.06 수준이었다. 이는 단일 feature만으로 주가 방향을 명확히 설명하기 어렵다는 점을 보여준다.

![Stock-search time-series overlay](figures/model1/10_stock_search_overlay.png)

주가와 검색량의 관계를 더 직관적으로 확인하기 위해 기업별 `Close`와 `weighted_trend`를 날짜축 기준으로 중첩하여 시각화하였다. 두 변수는 단위가 다르기 때문에 기업별로 min-max 정규화한 뒤 같은 축에 표시하였다. 분석 기간은 2025-06-10부터 2026-05-11까지이며, 각 기업별 관측치는 224개이다.

기업별 주가-검색량 상관계수는 삼성전자 0.13, 한화에어로스페이스 0.04, 현대차 -0.02, 네이버 -0.08, LG전자 -0.09, SK하이닉스 -0.51로 나타났다. 대부분 기업은 상관계수의 절댓값이 낮아 주가와 검색량이 일관된 방향으로 움직인다고 보기 어렵다. 특히 SK하이닉스는 검색량이 높았던 구간 이후 주가가 강하게 상승하면서 음의 상관관계가 크게 나타났는데, 이는 검색량 증가가 즉각적인 주가 상승 신호라기보다 이슈 확인, 불안 심리, 정보 탐색 수요를 함께 반영할 수 있음을 시사한다.

따라서 시계열 중첩 그래프에서도 검색량은 단독으로 주가 방향을 설명하기보다는 투자자 관심도와 시장 심리의 보조 지표로 해석하는 것이 적절하다. 검색량 변화가 실제 주가 변화로 연결되는지 판단하려면 뉴스 감성, 시장 지수, 금리, 환율, 거래량 변화 등 외부 요인을 함께 고려할 필요가 있다.

### 4.2 Experimental Setup

| 실험 항목 | 설정 |
|---|---|
| 모델 | Logistic Regression |
| 데이터 분할 | Train 70%, Validation 15%, Test 15% |
| 실제 분할 수 | Train 914, Val 196, Test 197 |
| 교차 검증 | TimeSeriesSplit, 5 folds |
| 주요 파라미터 | `max_iter=1000`, `class_weight="balanced"`, `random_state=42` |
| 하이퍼파라미터 실험 | `C = [0.001, 0.01, 0.1, 1, 10, 100]` |
| 평가 지표 | Accuracy, Precision, Recall, F1 Score, Confusion Matrix, ROC-AUC |
| 실험 환경 | Python 3.10.9, scikit-learn 기반 |

데이터는 시계열 특성을 가지므로 랜덤 셔플을 사용하지 않고 시간 순서를 유지하여 Train, Validation, Test로 분할하였다. 이는 미래 시점의 정보가 과거 학습에 들어가는 데이터 누수를 방지하기 위한 설정이다.

교차 검증도 일반 K-Fold가 아니라 `TimeSeriesSplit(n_splits=5)`를 사용하였다. 각 fold는 과거 데이터를 학습하고 이후 구간을 검증하는 방식으로 구성하였다.

Logistic Regression의 기본 파라미터는 다음과 같이 설정하였다.

```python
LogisticRegression(
    max_iter=1000,
    class_weight="balanced",
    random_state=42
)
```

`max_iter=1000`은 모델이 충분히 수렴하도록 반복 횟수를 늘린 설정이다. `class_weight="balanced"`는 클래스 비율 차이에 따른 학습 편향을 줄이기 위한 설정이다. `random_state=42`는 실험 재현성을 확보하기 위해 고정하였다.

추가로 정규화 강도를 조절하는 `C` 값을 변화시키며 하이퍼파라미터 변경 효과를 확인하였다. `C` 값이 작을수록 강한 정규화가 적용되고, 클수록 약한 정규화가 적용된다.

## 6. Analysis / Discussion

Logistic Regression 모델은 전체적으로 낮은 성능을 보였다. Test Accuracy는 0.4924, F1 Score는 0.4898, ROC-AUC는 0.4857로 나타났으며, 이는 무작위 예측 수준과 거의 유사하다. 따라서 현재 feature와 선형 모델 구조만으로는 주가 상승/하락 방향을 안정적으로 예측하기 어렵다고 판단된다.

성능이 낮게 나온 주요 원인은 데이터와 모델 특성에서 찾을 수 있다. 첫째, 주가 방향 예측은 검색량, 과거 수익률, 이동평균뿐 아니라 금리, 환율, 실적 발표, 뉴스, 시장 지수, 업종 흐름, 기업별 이슈, 투자자 심리 등 다양한 외부 요인의 영향을 받는다. 현재 데이터는 주가와 검색 트렌드 중심으로 구성되어 있어 실제 주가 변동을 설명하는 정보가 충분하지 않을 수 있다. 특히 검색량은 투자자의 관심과 불안, 기대감이 반영된 심리적 신호로 볼 수 있지만, 그 관심이 실제 매수로 이어졌는지 또는 단순한 이슈 확인에 그쳤는지는 주가 데이터만으로 구분하기 어렵다.

둘째, EDA 결과 `target`과 주요 feature 간 선형 상관관계가 낮았다. `weighted_trend`, `trend_lag1`, `return_lag1` 등은 target과의 상관계수가 절댓값 기준으로도 낮게 나타났다. Logistic Regression은 선형 결정 경계를 기반으로 하기 때문에, feature와 target 사이의 선형 관계가 약하면 성능이 제한될 수밖에 없다.

셋째, Confusion Matrix를 보면 실제 상승을 하락으로 예측한 FN이 58개로 많았다. 이는 모델이 상승 신호를 충분히 포착하지 못했다는 의미이다. 투자 관점에서 Recall이 낮다는 것은 실제 상승 기회를 놓칠 가능성이 크다는 점에서 한계가 있다.

중요 feature를 계수 기준으로 확인한 결과, 영향이 큰 변수는 `trend_lag3_mean`, `Open`, `weighted_trend`, `Close`, `ma20`, `trend_lag1` 등이었다.

![Top logistic regression coefficients](figures/model1/06_coefficients.png)

특히 `weighted_trend`, `trend_lag1`, `trend_lag3_mean`이 상위 변수에 포함된 점은 검색 트렌드 정보가 모델 판단에 사용되었음을 보여준다. 그러나 이 변수들이 실제 성능 향상으로 충분히 이어지지는 않았다.

### 6.1 Feature Importance 기반 심리학적 해석

계수 기반 중요도를 심리학적으로 해석하면, 검색 트렌드 변수는 투자자의 정보 탐색 행동과 시장 관심도를 나타내는 대리 변수로 볼 수 있다. `weighted_trend`는 국내 검색량과 글로벌 검색량을 외국인 비중으로 가중한 변수이므로, 단순 검색량보다 국내 투자자와 해외 투자자의 관심이 함께 반영된 심리 지표에 가깝다. 이 변수가 중요 feature로 나타난 것은 주가 방향 예측 과정에서 투자자들의 집단적 관심 변화가 일정 부분 참고되었음을 의미한다.

`trend_lag1`, `trend_lag3_mean`처럼 지연 검색량 변수가 상위에 포함된 점도 중요하다. 이는 투자자 심리가 당일 주가에 즉시 반영되기보다는, 이슈 인지, 정보 탐색, 판단, 매매 행동으로 이어지는 과정에서 시간 지연이 발생할 수 있음을 시사한다. 예를 들어 검색량 증가는 실적 발표, 뉴스, 급등락, 산업 이슈 등에 대한 관심 증가를 의미할 수 있으며, 이러한 관심은 단기적으로는 기대감이나 불안 심리를 반영한다. 다만 검색량 증가는 긍정적 관심과 부정적 관심을 모두 포함하기 때문에, 검색량이 높다고 해서 반드시 주가 상승으로 연결된다고 해석하기는 어렵다.

주가 기반 변수인 `Open`, `Close`, `ma20`이 함께 중요하게 나타난 점은 투자자 심리만으로 주가 방향이 결정되지 않음을 보여준다. 검색량이 시장의 관심과 심리적 반응을 나타낸다면, 가격 변수와 이동평균 변수는 실제 매매 결과와 추세를 반영한다. 즉, 모델은 "사람들이 얼마나 관심을 보였는가"와 "가격이 실제로 어떤 위치와 흐름에 있는가"를 동시에 활용하려고 했지만, 두 신호 사이의 관계가 안정적이지 않아 예측 성능은 제한적으로 나타났다.

외부 요인의 부족도 이 해석을 뒷받침한다. 검색량이 급증한 원인이 호재인지 악재인지, 해당 시점에 금리나 환율이 어떻게 움직였는지, 시장 전체가 상승장이었는지 하락장이었는지, 뉴스 감성이 긍정적인지 부정적인지에 대한 정보가 없으면 투자자 심리를 한 방향으로 해석하기 어렵다. 따라서 현재 feature importance 결과는 "검색 트렌드가 투자자 심리 신호로서 모델에 사용되었다"는 점은 보여주지만, 그 심리가 주가 상승 또는 하락으로 안정적으로 전환되는 구조까지 설명하기에는 한계가 있다.

결론적으로 feature importance 분석에서 검색 트렌드 관련 변수가 상위에 포함된 것은 투자자 관심과 정보 탐색 심리가 주가 예측에 일정한 설명력을 가질 가능성을 보여준다. 그러나 현재 모델 성능과 낮은 상관관계를 함께 고려하면, 검색량은 독립적인 예측 신호라기보다 주가, 시장 상황, 뉴스 감성, 거시경제 변수와 결합될 때 더 의미 있는 심리 지표로 활용될 수 있다. 이후 분석에서는 검색량을 단순 수치로만 사용하기보다 뉴스 감성, 시장 지수, 환율, 금리, 거래량 변화와 함께 해석하여 투자자 심리의 방향성과 강도를 구분할 필요가 있다.

![Predicted probability distribution](figures/model1/07_probability_distribution.png)

예측 상승 확률 분포를 보면 실제 0과 실제 1의 확률 분포가 명확히 분리되지 않는다. 많은 샘플이 결정 기준인 0.5 주변에 몰려 있어 모델이 상승과 하락을 확신 있게 구분하지 못했음을 알 수 있다.

![Learning curve](figures/model1/08_learning_curve.png)

Learning Curve를 보면 학습 정확도는 약 0.57 수준, 검증 정확도는 최종적으로 약 0.47 수준까지 낮아졌다. 학습 정확도 자체도 높지 않기 때문에 강한 과적합이라기보다는 언더피팅 성격이 더 크다. 즉, 모델이 학습 데이터에서도 충분히 강한 패턴을 학습하지 못했다.

하이퍼파라미터 실험에서는 `C=0.001`처럼 강한 정규화를 적용했을 때 Validation Accuracy와 ROC-AUC가 가장 높게 나타났다. 그러나 최고 성능도 Validation Accuracy 0.5153, ROC-AUC 0.5316 수준에 그쳤다. 이는 단순히 `C` 값을 조정하는 것만으로는 큰 성능 개선이 어렵다는 점을 보여준다.

모델 선택 관점에서 Logistic Regression은 해석 가능성이 높고 빠르게 학습할 수 있기 때문에 baseline 모델로 적합하다. 또한 계수를 통해 어떤 feature가 예측에 영향을 주는지 확인할 수 있다는 장점이 있다. 하지만 주가 방향 예측처럼 비선형적이고 외부 요인이 많은 문제에서는 Logistic Regression만으로는 한계가 크다.

따라서 본 모델은 최종 모델이라기보다 기준 성능을 제시하는 baseline으로 활용하는 것이 적절하다. 후속 실험에서는 Random Forest, XGBoost와 같은 비선형 모델을 적용하여 변수 간 복잡한 상호작용을 반영하고, 뉴스 감성, 시장 지수, 환율, 금리, 업종 지수, 실적 발표 여부 등 외부 변수를 추가하여 성능 개선 가능성을 확인할 필요가 있다. 또한 검색량 변수를 투자자 심리 지표로 활용하려면 검색량 증가의 원인이 긍정적 기대인지 부정적 불안인지 구분할 수 있는 보조 변수를 함께 사용하는 것이 중요하다.
