# 💻 소스 코드 (src/)

시스템의 핵심 로직이 구현된 소스 코드 디렉토리입니다.

## 📁 모듈 구조

### 1. `utils/`
- `config.py`: 프로젝트 전역 설정 (경로, 티커 리스트, 모델 파라미터)
- `helpers.py`: 기술적 지표 계산 함수 및 공통 보조 도구

### 2. `processing/`
- `processor.py`: 데이터 로드, 병합, 피처 생성, 정규화(Scaling)
- `selector.py`: 변수 중요도 기반 최적 피처 선택 (Feature Selection)

### 3. `models/`
- `classifier.py`: 앙상블 모델 정의 및 학습 로직
- `evaluator.py`: 모델 평가 지표 산출 및 검증 리포팅

### 4. `main.py`
- 전체 파이프라인을 오케스트레이션하는 진입점(Entry Point)

## 🛠️ 코드 작성 원칙
- **모듈화**: 각 기능은 독립적인 함수나 클래스로 작성합니다.
- **로깅**: 주요 단계마다 실행 상태를 확인할 수 있는 로그를 남깁니다.
- **일관성**: `GEMINI.md`에 정의된 데이터 처리 및 모델링 수칙을 엄격히 준수합니다.
